プライバシー

最終更新日：2026年10月30日

MKC+ は利用者を監視しません

今のアプリの多くは、利用者の操作に関する情報を集めてどこかへ送ります。MKC+ はその逆の考え方で作られました。アカウントも、利用状況の分析も、広告も、追跡も、履歴もなく、利用者が誰なのかも知りません。入力、コピー、移動、ドロップしたものがローカルネットワークの外に出ることはありません。

デバイス同士だけでやりとりします

マウスの操作、キー入力、クリップボードの内容、ファイルは、自分のネットワークを通ってデバイスからデバイスへ直接送られ、エンドツーエンドで暗号化されます。間に入るサーバーはありません。

インターネットに出るものは、これだけです

  • 自分で選んで送るフィードバック。Google Play 版のアプリでは、それ以外のものがインターネットに出ることはありません。
  • 1日1回のアップデート確認。Windows、macOS、Linux 用の MKC+ と、mkcplus.com から入手した Android アプリが行います（Google Play 版は Google Play がアップデートします）。この確認は Cloudflare 上のカウンターを通り、カウンターは OS と、Cloudflare が接続から読み取る国と地域、ネットワーク名、現地の時刻（何時台か）について、その日の合計に1を加えます。IP アドレスもデバイスの識別子も保存しないため、誰のものかを知ることなくインストール数を数えます。ネットワーク別と地域別の合計は90日後に削除されます。MKC+ の dnf リポジトリを使う Linux マシンは、新しいバージョンもそのつどこのカウンターを通して取得します。このときカウンターは、バージョン、dnf が伝える OS、国について1を加えます。

フィードバックを送るとき

MKC+ が利用者に関する情報を送るのはフィードバックのときだけで、送るのは自分で選んだものだけです。メッセージと、追加した場合は名前、メールアドレス、スクリーンショット、画像、診断パッケージ（システムの詳細、設定、ネットワークアドレス、デバイスの識別子、最近のログ）です。フィードバックは暗号化された接続で Cloudflare 上の私たちの中継サーバーに送られ、開発者だけが読める GitHub の非公開の項目として保存されます。スクリーンショットと画像は30日後に削除されます。中継サーバーは IP アドレスとデバイスの識別子を最長20分間だけ保持します。中継サーバーへの大量送信を防ぐためだけです。

Android の権限

「ユーザー補助」は、ほかのデバイスのマウスとキーボードでスマートフォンを操作できるようにします。MKC+ が読み取るのは、クリックやスクロールのためにマウスカーソルの下にあるものだけで、画面のそれ以外の部分を読み取ることはありません。クリップボードを読み取るのは、マウスカーソルが別のデバイスへ移るときだけで、移った先で貼り付けられるようにするためです。画面の画像を撮影するのは、ほかのデバイスに壁紙を表示するための1回と、フィードバックにスクリーンショットを追加した場合のもう1回だけです。マウスが別のデバイスにある間は、スマートフォンに接続したキーボードのキー入力をそのデバイスへ送ります。これらはいずれも、フィードバックとして送らないかぎり、自分のデバイスの外に出ることはありません。

データの削除

私たちが保持しうるデータは、送っていただいたフィードバックだけです。削除を希望する場合は、フィードバックに使ったアドレスから、または送った日付を添えて、support@mkcplus.com までメールを送ってください。30日以内に削除します。

子ども

MKC+ は13歳未満の子どもを対象としたものではありません。

このウェブサイト

mkcplus.com は Cloudflare Web Analytics を使用しています。これは Cookie を設定せず、ほかのサイトまで追跡することもありません。ダウンロードボタンを押すと、ページはどのボタンかとページの言語を同じカウンターに伝え、カウンターはそれらと国について、その日の合計に1を加えます。ここでも IP アドレスや識別子は保存しません。
