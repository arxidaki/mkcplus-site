よくある質問

MKC+ とは何ですか？

MKC+ は、同じローカルネットワーク上の Windows PC、Appleシリコン搭載の Mac、Linux マシン、Android のスマートフォン、タブレット、テレビを、1組のマウスとキーボードで使えるようにする無料のベータ版アプリです。マウスカーソルを画面の端の外へ動かすと隣のデバイスに現れ、キーボードの入力先もそのデバイスに切り替わります。サーバーになるデバイスはありません。どの PC や Mac のマウスとキーボードでも、ほかのどのデバイスでも操作できます。Android のスマートフォンやタブレットからも、ほかのデバイスを操作できます。その MKC+ ウインドウでデバイスをダブルタップすると、キーボード付きのトラックパッドである Remote が開きます。また、タブレットに接続したマウスとキーボードでも、PC と同じようにマウスカーソルを隣の画面に移して、そのデバイスを操作できます。Android のテレビは操作される側専用です。

無料ですか？

はい。MKC+ は無料のベータ版で、有料版はなく、デバイスごとの料金もかかりません。オープンソースではなく、ベータ版のため保証なしで現状のまま提供されます。

どのシステムで動きますか？

Windows PC（Intel または AMD、および ARM）、Appleシリコン搭載の Mac、Wayland を使う Linux PC（Ubuntu 22.04 以降、Debian 12 以降、Fedora 36 以降）、そして Android 10 以降の Android スマートフォン、タブレット、テレビ（Android TV と Google TV）です。キーボードから Android デバイスに文字を入力するには Android 13 以降が必要です。Intel 搭載の Mac では動作せず、X11 を使う Linux デスクトップでも動作しません。

アカウントやインターネット接続は必要ですか？

いいえ。MKC+ にはアカウントがなく、入力、コピー、移動したものがサーバーを経由することはありません。デバイス同士がローカルネットワーク上で直接やりとりします。インターネットを使うのは、自動でインストールされるアップデートのダウンロード（Android では確認を求められます）と、自分で選んでフィードバックを送るときだけです。

通信は暗号化されていますか？

はい。2台のデバイスは、両方の画面に表示される6桁のコードを見比べてペアリングします。その後、デバイス間で送られるキー入力、マウスカーソルの動き、クリップボード、ファイルは暗号化され、認証されます。MKC+ はベータ版で、第三者によるセキュリティ監査はまだ受けていません。

どうやって設定しますか？

各デバイスに MKC+ をインストールして開きます。Mac では、許可を求めるウインドウが表示されたら「入力監視」と「アクセシビリティ」（macOS 27 以降では「デバイスの制御とデータへのアクセス」）を許可してください。Android では MKC+ の「ユーザー補助」をオンにしてください。手順は MKC+ の「権限」ウインドウに表示されます。Linux では、デスクトップが初回に表示する2つの要求を許可してください。1つはマウスカーソルとキーボードを共有するため、もう1つはこのマシンを操作できるようにするためです。両方のデバイスが同じネットワークにあれば、新しいデバイスがもう一方の MKC+ ウインドウに表示されます。そこで「ペアリング」を押し、新しいデバイスで両方の画面に同じ6桁のコードが表示されていることを確かめて「承認」を押します。最後に、ウインドウ内のデバイスをドラッグして、デスク上の並びに合わせます。

Wi-Fi で使えますか？

MKC+ は Wi-Fi、有線LAN、スマートフォンの USB テザリング、またはその複数を同時に使って動作します。すべての接続を常にテストして最適なものを使い、どれかが切れると自動で切り替えます。デバイスは同じローカルネットワークにある必要があります。MKC+ がモバイルデータを使うことはありません。

MKC+ はどのポートを使いますか？

UDP ポート 47653 と 47654、TCP ポート 47654 を、ローカルネットワーク上でのみ使います。ファイアウォールがこれらをブロックしている場合は、どのデバイスを直せばよいかを MKC+ ウインドウが知らせます。

Windows、Mac、Android の間でコピー＆ペーストできますか？

はい。あるデバイスでコピーし、マウスカーソルを別のデバイスに移して貼り付けます。PC と Mac の間では、テキスト、書式付きテキスト、画像、PDF に加えて、ファイルとフォルダもやりとりでき、ドラッグで移すこともできます。Android のスマートフォン、タブレット、テレビとは、テキストと画像を双方向でやりとりできます。Android からファイルを送るには、ファイルを MKC+ に共有し、PC または Mac で貼り付けます。PC や Mac でコピーしたファイルは、Android 側に「ダウンロードに保存」付きの通知で表示されます。ファイルのコピーは最も新しい機能で、ベータ版ではまだ制限があります。

マウスカーソルが別のデバイスから戻らなくなったら？

使っているキーボードで Ctrl + Alt + Shift + Esc（Mac では command + option + shift + esc）を押すと、マウスカーソルとキーボードがすぐにそのデバイスに戻ります。

インストール時に Windows、macOS、Android が警告を表示するのはなぜですか？

MKC+ のインストーラーは商用の証明書で署名されていないため、Windows SmartScreen が一度だけ警告します（「詳細情報」、次に「実行」）。Mac では、「システム設定」の「プライバシーとセキュリティ」で「このまま開く」を押して、インストーラーを一度だけ許可します。Android アプリはアプリストアではなく mkcplus.com から入手する APK ファイルなので、ブラウザーやファイルアプリからのインストールを許可するよう Android に求められ、Google Play プロテクトが見慣れないアプリとして警告することがあります。MKC+ がマウスカーソルを動かしたり文字を入力したりするには、Android の「ユーザー補助」の権限が必要です。Android 13 以降では、先に MKC+ の「制限付き設定を許可」を行います。手順は MKC+ の「権限」ウインドウに表示されます。Linux では警告は出ません。.deb と .rpm は他のパッケージと同じようにインストールでき、AppImage は開く前に実行可能にするだけです。これはベータ期間中は想定どおりの動作です。MKC+ は必ず mkcplus.com からダウンロードしてください。その後は MKC+ が自動でアップデートし、すべてのアップデートを独自の署名鍵で確認します。

データを収集しますか？

MKC+ は利用者を追跡しません。アカウントも ID もテレメトリも履歴もありません。だからこそフィードバックはとても貴重です。ぜひお聞かせください。
