MKC+ ไม่ได้จับตาดูคุณ

ทุกวันนี้แอปส่วนใหญ่เก็บข้อมูลเกี่ยวกับสิ่งที่คุณทำแล้วส่งไปที่ใดที่หนึ่ง MKC+ ออกแบบมาให้ต่างออกไป ไม่มีบัญชี ไม่มีการวิเคราะห์การใช้งาน ไม่มีโฆษณา ไม่มีการติดตาม ไม่มีประวัติ และไม่รู้ว่าคุณเป็นใคร สิ่งที่คุณพิมพ์ คัดลอก ย้าย หรือลากไปวาง ไม่มีวันออกนอกเครือข่ายภายในของคุณ

อุปกรณ์ของคุณสื่อสารกันเองเท่านั้น

ข้อมูลจากเมาส์ คีย์บอร์ด และคลิปบอร์ด รวมถึงไฟล์ของคุณ จะถูกส่งตรงจากอุปกรณ์เครื่องหนึ่งของคุณไปยังอีกเครื่องหนึ่งผ่านเครือข่ายของคุณเอง โดยเข้ารหัสตั้งแต่ต้นทางถึงปลายทาง ไม่มีเซิร์ฟเวอร์คั่นกลาง

สิ่งที่ส่งไปยังอินเทอร์เน็ต มีเพียงเท่านี้

  • คำติชม หากคุณเลือกส่ง แอปจาก Google Play จะไม่ส่งข้อมูลอื่นใดไปยังอินเทอร์เน็ตเลย
  • การตรวจหาอัปเดตวันละหนึ่งครั้ง ใน MKC+ สำหรับ Windows, macOS และ Linux และในแอป Android จาก mkcplus.com (Google Play อัปเดตตัวที่ติดตั้งจาก Play เอง) การตรวจนี้ผ่านตัวนับบน Cloudflare ซึ่งเพิ่มยอดรวมของวันนั้นขึ้นหนึ่ง โดยแยกตามระบบและข้อมูลที่ Cloudflare อ่านได้จากการเชื่อมต่อ ได้แก่ ประเทศและภูมิภาค ชื่อเครือข่าย และชั่วโมงตามเวลาท้องถิ่น ตัวนับไม่เก็บที่อยู่ IP และไม่เก็บตัวระบุอุปกรณ์ จึงนับจำนวนการติดตั้งได้โดยไม่รู้ว่าเป็นของใคร ยอดรวมตามเครือข่ายและภูมิภาคจะถูกลบหลังจาก 90 วัน เครื่อง Linux ที่ใช้คลังแพ็กเกจ dnf ของ MKC+ ยังดาวน์โหลดเวอร์ชันใหม่แต่ละเวอร์ชันผ่านตัวนับนี้ด้วย ซึ่งจะเพิ่มยอดนับขึ้นหนึ่ง โดยแยกตามเวอร์ชัน ระบบที่ dnf ระบุ และประเทศ

เมื่อคุณส่งคำติชม

การส่งคำติชมเป็นกรณีเดียวที่ MKC+ ส่งข้อมูลใด ๆ เกี่ยวกับคุณ และส่งเฉพาะสิ่งที่คุณเลือก คือข้อความของคุณ และหากคุณเพิ่มเข้าไป ก็รวมถึงชื่อ ที่อยู่อีเมล ภาพหน้าจอ รูปภาพ และแพ็กเกจการวินิจฉัย (รายละเอียดระบบ การตั้งค่า ที่อยู่เครือข่าย ตัวระบุอุปกรณ์ และไฟล์บันทึกล่าสุด) ข้อมูลนี้ส่งผ่านการเชื่อมต่อที่เข้ารหัสไปยังตัวส่งต่อของเราบน Cloudflare และบันทึกเป็นรายการส่วนตัวบน GitHub ที่มีเพียงผู้พัฒนาเท่านั้นที่อ่านได้ ภาพหน้าจอและรูปภาพจะถูกลบหลังจาก 30 วัน ตัวส่งต่อเก็บที่อยู่ IP และตัวระบุอุปกรณ์ของคุณไว้ไม่เกิน 20 นาที เพียงเพื่อป้องกันไม่ให้ใครส่งคำขอเข้ามาถล่มเท่านั้น

สิทธิ์บน Android

สิทธิ์ การช่วยเหลือพิเศษ ทำให้เมาส์และคีย์บอร์ดของอุปกรณ์อื่นของคุณควบคุมโทรศัพท์ของคุณได้ MKC+ อ่านเฉพาะสิ่งที่อยู่ใต้เคอร์เซอร์เพื่อคลิกและเลื่อน ไม่อ่านส่วนอื่นของหน้าจอเลย MKC+ อ่านคลิปบอร์ดเฉพาะเมื่อเคอร์เซอร์ออกไปยังอุปกรณ์อื่น เพื่อให้คุณวางที่นั่นได้ MKC+ ถ่ายภาพหน้าจอหนึ่งครั้งเพื่อแสดงวอลเปเปอร์ของคุณบนอุปกรณ์อื่นของคุณ และอีกหนึ่งครั้งเฉพาะเมื่อคุณเพิ่มภาพหน้าจอไปกับคำติชม ขณะที่เมาส์ของคุณอยู่บนอุปกรณ์อื่น MKC+ จะส่งการกดแป้นของคีย์บอร์ดที่เชื่อมต่อกับโทรศัพท์ของคุณไปที่นั่น ทั้งหมดนี้ไม่ออกจากอุปกรณ์ของคุณเอง เว้นแต่คุณจะส่งไปเป็นคำติชม

การลบข้อมูลของคุณ

ข้อมูลเดียวที่เราอาจเก็บไว้ได้คือคำติชมที่คุณส่งมา หากต้องการให้ลบ โปรดส่งอีเมลถึง support@mkcplus.com จากที่อยู่ที่คุณใช้ หรือแจ้งวันที่ที่คุณส่ง แล้วเราจะลบให้ภายใน 30 วัน

เด็ก

MKC+ ไม่ได้มุ่งให้บริการแก่เด็กอายุต่ำกว่า 13 ปี

เว็บไซต์นี้

mkcplus.com ใช้ Cloudflare Web Analytics ซึ่งไม่ตั้งคุกกี้และไม่ตามคุณไปยังเว็บไซต์อื่น เมื่อคุณกดปุ่มดาวน์โหลด หน้าเว็บจะบอกตัวนับเดียวกันนี้ว่าเป็นปุ่มใดและหน้าเว็บเป็นภาษาใด แล้วตัวนับจะเพิ่มยอดรวมของวันนั้นขึ้นหนึ่ง โดยแยกตามปุ่ม ภาษา และประเทศของคุณ ที่นี่ตัวนับก็ไม่เก็บที่อยู่ IP และตัวระบุใด ๆ เช่นกัน
