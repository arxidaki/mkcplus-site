# MKC+ website

**Visit the site: [mkcplus.com](https://mkcplus.com)**

This repository holds the published files of [mkcplus.com](https://mkcplus.com), the
website and download page of MKC+. MKC+ lets you use one mouse and keyboard across your
devices on your local network, and copy & paste between them.

- Website and downloads: [mkcplus.com](https://mkcplus.com)
- Releases and notes: [arxidaki/mkcplus-releases](https://github.com/arxidaki/mkcplus-releases/releases)

The files here are generated and replaced on every publish, so pull requests are not
accepted here.
