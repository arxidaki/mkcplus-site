Agents

Add MKC+ to your AI agent on the device the agent runs on, with MKC+ installed there. The first time the agent uses MKC+, the MKC+ window on that device asks you to allow it. Each device then asks before the agent first uses it, and, where the device can tell which app is in front, before it first uses each app there.

MKC+ sends nothing about agents anywhere: there is no account, relay or telemetry, and each device keeps its own record of what agents did there. What an agent sees, it sends to its own service, as with anything else you show it.

On Android, agents can see and use a phone or tablet that has MKC+ from this site.

Using the AppImage? Give the agent the AppImage's own file in place of /usr/libexec/mkcplus/mkcplusd, and --engine mcp in place of mcp. The Claude Code plugin is for the .deb and .rpm.
